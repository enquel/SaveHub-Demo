# SaveHub Demo (Windows)

Free playable demo of SaveHub, a save game system for Unreal Engine 5.8.

Download `SaveHub_Demo_Win64_v1.0.zip` from [Releases](https://github.com/enquel/SaveHub-Demo/releases/latest), unzip, run `SaveHubDemo.exe`. Windows 10/11 64-bit, no install or account.

Walk around (WASD, mouse, Space), open doors, push cubes, collect orbs, spawn crates. Press Tab, name a slot, Save. Change the world, Load the slot and it comes back. Share as text turns a slot into text you can paste back in.
